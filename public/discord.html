Invite bot to your server ↗

Use your existing bot application

  1. In the Discord Developer Portal, open your Jarvis application. Copy its Application ID from General Information.
  2. Open Bot and copy or reset the bot token. Enter it only below. Never send the token in chat.
  3. In Discord, enable Developer Mode under Settings → Advanced. Right-click your server, your user and the voice channels you want Jarvis to use, then Copy ID.
  4. Save this form, use the generated invite link and authorize the bot in your existing server. It needs View Channels, Send Messages, Attach Files, Connect and Speak. No Administrator permission or Message Content intent is needed.
  5. Return here and select Connect Discord. Slash commands register in your selected server.

Jarvis can join only these voice channels, only when a linked user in that channel asks it to. Leave blank to finish text setup first.

Linked Discord users

Link each person’s Discord user ID to their Jarvis profile and room. Unlinked users cannot send commands or have their audio processed.

Talk to Jarvis

  • /jarvis ask — type a question or household command; the reply is private to you.
  • /jarvis join — join an approved voice channel.
  • Say “Hey Jarvis, what’s the weather?” Voice audio is transcribed locally. Voice replies are audible to everyone in the channel.
  • /jarvis last — read your latest answer privately, including voice requests.
  • /jarvis stop — stop your current request or spoken reply.
  • /jarvis leave — disconnect from voice.

Use short voice requests under twenty seconds. Only one voice request is processed at a time. Jarvis stays out of voice channels after restart until invited again. Discord audio reception is supported by the voice library but not officially documented by Discord, so a live channel test is required. Household commands act in the assigned room and may update its Jarvis screen. Private individual calendars are not connected.
