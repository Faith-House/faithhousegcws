A Jarvis voice built from the prepared Marvel reference. Speech generation runs on this computer.

Checking Voicebox…

Open the installed Voicebox app from the Windows Start menu and keep it running. Prepare imports the eight-second reference and downloads the local voice model. Test and use generates a real preview before switching Jarvis’s voice.

This uses Qwen TTS 0.6B for the reference voice. CPU generation can take a minute or longer on this laptop. Text appears first; Stop speaking cancels generation. Peter remains available in the voice menu. The current voice remains selected until a playable preview succeeds. This setup changes the spoken voice, leaving roommate voice recognition intact.
