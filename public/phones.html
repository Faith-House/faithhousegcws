Open secure Jarvis

The phone and computer must be on the same trusted Wi-Fi. Run SETUP-PHONE.cmd on the computer once if access is not enabled. The setup page only serves the public certificate and connection instructions; all Jarvis requests use HTTPS.

Trust the local certificate

Download Jarvis Local Phone CA from the setup address on your phone. Compare its fingerprint here before trusting it.

On iPhone, install the downloaded profile in Settings, then enable SSL trust in Settings → General → About → Certificate Trust Settings. On Android, install the downloaded file as a CA certificate in your device’s security/credential settings; labels vary by manufacturer.

Only the public CA certificate is downloaded. Keep the CA signing key and server private key on this computer. Removing the phone pairing revokes Jarvis access; remove the certificate separately in your phone’s settings if you no longer use it.

Pair a phone

Enter this code in secure Jarvis on the phone within five minutes. It works once. No voice recording is required.

Paired phones

    Pairings last 30 days and can be revoked here. A phone can send commands only to its assigned room/profile and stop only its own latest request. Household data in that room is shared; profile selection is not private-calendar sign-in. Router port forwarding, cellular access and background phone wake-word listening are not enabled.
