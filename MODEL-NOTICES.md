# Model attribution

- Wake detection uses David Scripka’s [openWakeWord](https://github.com/dscripka/openWakeWord), release v0.5.1: melspectrogram.onnx, embedding_model.onnx, and hey_jarvis_v0.1.onnx. Upstream identifies its code as Apache-2.0 and its distributed pretrained models as [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). See the [upstream license section](https://github.com/dscripka/openWakeWord#license). This is a personal house-assistant setup.
- The wake feature backbone derives from Google’s speech embedding model, attributed upstream.
- Recognition uses [ONNX Community whisper-tiny.en](https://huggingface.co/onnx-community/whisper-tiny.en), a conversion of Whisper, under MIT terms.
- Neural output uses [Kokoro](https://github.com/hexgrad/kokoro) and the [ONNX Community Kokoro-82M-v1.0 conversion](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX), under Apache-2.0 terms.
- Optional neural output also uses Kyutai’s [Pocket TTS](https://github.com/kyutai-labs/pocket-tts), code version 4.0.1 (MIT), with the pinned english_2026-10 release and [without-voice-cloning model](https://huggingface.co/kyutai/pocket-tts-without-voice-cloning) (CC BY 4.0), revision a7056f505a4a8ca72d8b5fb1440071d6f1a35739. Charles derives from the CSTR VCTK Corpus, University of Edinburgh, speaker p254, via Kyutai’s enhanced stock voice. Peter derives from Peter Yearsley’s LibriVox recordings, curated by Voice-Zero and released there as CC0. See [Kyutai voice attributions](https://huggingface.co/kyutai/tts-voices) and [Voice-Zero](https://github.com/OwenTyme/voice-zero). Runtime uses only downloaded stock embeddings; no custom voice-cloning input is exposed.
- Speaker matching uses [WeSpeaker ResNet34-LM](https://huggingface.co/Wespeaker/wespeaker-voxceleb-resnet34-LM), via the unmodified [ONNX Community conversion](https://huggingface.co/onnx-community/wespeaker-voxceleb-resnet34-LM), under CC BY 4.0. The model manifest pins revision 6a61a1833ff2583aabeba044f5c8221f00b67ceb and records the verified weights hash. WeSpeaker is by the wenet-e2e/WeSpeaker contributors; the model card provides paper citations.

Model manifests record source revision/release, sizes, and SHA-256 hashes. Downloads verify published digests where available, otherwise recording the checked size and calculated digest. Models are unmodified. Runtime loading uses local files only.

The listening fixtures are generated Windows David/Zira speech saying “Hey Jarvis”; they contain no user microphone recording. Model files live under models/ and are excluded from source control.
